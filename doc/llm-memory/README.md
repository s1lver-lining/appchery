# LLM memory

Findings that cost real time to establish and that a fresh session would otherwise re-derive:
hardware answers, platform limits, and the reasons a design went one way rather than another.

Not a place for anything the code already says. A file here earns its keep by recording what was
measured, on what, and when, so the next session can trust it or knows to re-check it.

Each file states the date and the hardware it was verified on. A finding without those is a rumour.
